조례 입안 협업 IDE의 기능 명세. **무엇을(WHAT)·왜(WHY)**에 집중하고 구현 방법(HOW)은 [plan.md](plan.md)로 미룬다.

## 제품 한 줄

지자체 법무 담당자가 조례 카테고리별 의도만 던지면, AI가 표준 구조와 입안·정비 기준에 맞게 조례 문장을 단계적으로 써 내려가는 도구.

---

## User Stories (우선순위 순)

### US1 (P1) — 입안 프로젝트 시작
**As a** 지자체 법무 담당자
**I want** 작업 종류(제정 / 일부개정 / 전부개정)를 선택하고 새 입안 프로젝트를 시작
**So that** 작업 성격에 맞는 워크스페이스에서 바로 입안을 시작할 수 있다

- 제정: 백지에서 시작
- 일부개정·전부개정: 기존 조례를 로드(파일 업로드 / 국가법령정보센터 검색 / 직접 붙여넣기)

### US2 (P1) — 단계별 AI 협업 작성
**As a** 담당자
**I want** 각 단계에서 의도를 프롬프트로 지시하면 AI가 조문 문장을 작성
**So that** 표준 구조와 기준을 모두 외우지 않고도 규격에 맞는 조례를 쓸 수 있다

- 담당자는 의도·방향·수정 지시만 한다 (AI=작성자, 담당자=디렉터)
- AI가 작성한 모든 문장은 근거 위키 섹션을 토글로 확인 가능 (헌법 P1)

### US3 (P1) — 단계 잠금·확정 진행
**As a** 담당자
**I want** 한 단계를 완성·확정해야 다음 단계가 열리고, 확정된 단계는 언제든 다시 수정
**So that** 누락된 채로 입안이 끝나는 일을 방지하면서도 회귀 수정이 자유롭다

- 표준 8단계: 제명 → 목적 → 정의 → 적용범위 → 본칙 → 부칙 → 검토 → 완성
- 이전 단계 미확정 시 다음 단계 진입 불가 (헌법 P2)
- 확정 단계 수정 시 이후 단계는 재검토 필요(stale) 표시

### US4 (P1) — 단계 확정 시 기준 검증
**As a** 담당자
**I want** 작성 중에는 가벼운 힌트를, 단계 확정 시에는 입안·정비 기준 매트릭스로 정밀 검증
**So that** 기준 위반을 조기에 발견하고 확정 전에 바로잡을 수 있다

- 위반 시: AI 수정 제안 수용 / 직접 수정 / 사유 기록 후 무시 중 선택
- 검증 무시는 사유 입력 강제 (헌법 P6)
- 검증은 1조문 × 1기준 단위로 수행, 전 매트릭스가 채워졌는지 확인 (헌법 P3)

### US5 (P2) — 본칙 동적 구성
**As a** 담당자
**I want** AI가 제명·목적을 분석해 필요한 본칙 항목(위원회·보조·위탁 등)을 추천하고, 내가 체크박스로 확정
**So that** 조례 성격에 맞는 본칙만 구성하고 불필요한 항목을 배제할 수 있다

- 확정된 본칙 항목들은 각각 sub-stage가 되어 모두 완료해야 부칙으로 진행

### US6 (P2) — 개정 모드 diff 작업
**As a** 담당자
**I want** 개정 작업 시 원본과 개정안을 나란히 보고 변경 사항을 diff로 확인
**So that** 무엇이 바뀌는지 항상 가시화된 상태로 개정안을 작성할 수 있다

- 원본은 읽기 전용 유지, 모든 변경은 개정안 버퍼에서 발생
- 조 단위로 변경/추가/삭제 카운트 표시
- 일부개정은 변경된 조만 출력에 포함

### US7 (P2) — 타 지자체 조례 참조
**As a** 담당자
**I want** 유사 조례를 검색해 AI 컨텍스트에 첨부
**So that** 다른 지자체 선례를 참고하여 더 나은 조문을 작성할 수 있다

- 데이터 소스: 국가법령정보센터 자치법규 OpenAPI
- 참고 조례는 "참고하되 복제 금지"를 AI에 명시 (헌법 P4)

### US8 (P3) — 이력·시간여행
**As a** 담당자
**I want** 단계별 프롬프트·AI 응답·확정 이력을 시간순으로 보고 특정 시점으로 되돌아보기
**So that** 의사결정을 추적하고 이전 상태를 복원할 수 있다

### US9 (P3) — 최종안 출력
**As a** 담당자
**I want** 완성된 조례를 표준 형식 문서로 내보내기
**So that** 의회 제출·내부 결재에 바로 사용할 수 있다

- 출력 형식: v1은 DOCX / PDF (HWP/hwpx는 후순위, 별도 결정)

### US10 (P3) — 다중 참조 워크스페이스
**As a** 담당자
**I want** 원본·개정안·위키·참고 조례를 동시에 탭·분할로 열어두고 작업
**So that** 여러 문서를 오가며 참조하는 법무 작업을 끊김 없이 할 수 있다

## Functional Requirements

- **FR-001** 시스템은 세 가지 작업 종류(제정/일부개정/전부개정)로 프로젝트를 분기해야 한다
- **FR-002** 개정 모드는 기존 조례를 3가지 방법(업로드/OpenAPI 검색/붙여넣기)으로 로드할 수 있어야 한다
- **FR-003** 시스템은 표준 8단계를 선형 잠금하고, 이전 단계 확정 전 다음 단계 진입을 막아야 한다
- **FR-004** 확정된 단계 수정 시 이후 단계를 stale로 표시해야 한다
- **FR-005** AI가 생성한 각 조문은 근거 위키 섹션을 추적·표시할 수 있어야 한다
- **FR-005a** AI는 입안·정비 기준에 근거가 없는 내용을 "기준에 없음"으로 명시 표시해야 하며, 근거를 지어내지 않아야 한다 (헌법 P1)
- **FR-006** 작성 중 가벼운 인라인 힌트를 제공해야 한다
- **FR-007** 단계 확정 시 입안·정비 기준 매트릭스로 정밀 검증하되, 1조문×1기준 단위로 평가하고 전 셀이 채워졌는지 검증해야 한다
- **FR-008** 검증 위반 무시 시 사유 입력을 강제하고 이력에 기록해야 한다
- **FR-009** AI는 제명·목적을 분석해 본칙 항목을 추천하고, 담당자 선택분만 sub-stage로 구성해야 한다
- **FR-010** 개정 모드는 원본↔개정안 diff와 조 단위 변경 카운트를 제공해야 한다
- **FR-011** 타 지자체 조례를 검색·첨부하되 복제 금지 지시를 AI에 포함해야 한다
- **FR-012** 단계별 프롬프트·응답·확정 이력을 시간순으로 보존하고 시점 복원을 지원해야 한다
- **FR-013** 완성된 조례를 DOCX·PDF로 내보낼 수 있어야 한다 (HWP/hwpx 후순위)
- **FR-014** 한 화면에서 여러 문서를 탭·분할로 동시에 열 수 있어야 한다
- **FR-015** WCAG 2.1 AA를 충족해야 한다 (3중 인코딩, 키보드 전체 접근, 대비)
- **FR-016** 조례 본문은 조(條) 단위로 저장하고, 항·호는 본문 텍스트 내 마크업으로 표현해야 한다

## Success Criteria

- **SC-001** 담당자가 조례 1건을 백지에서 8단계 완주하여 검증 통과 산출물까지 만드는 데 성공한다
- **SC-002** AI가 생성한 모든 조문에 대해 근거 위키 섹션을 100% 표시한다 (근거 없는 조문 0건)
- **SC-003** 정밀 검증 매트릭스의 모든 셀(조문×기준)이 빠짐없이 채워진다 (누락 0건)
- **SC-004** 잠금된 단계로의 우회 진입이 0건이다
- **SC-005** 개정 모드에서 원본 대비 변경 사항이 조 단위로 정확히 시각화된다
- **SC-006** 검증 위반 무시 건은 100% 사유가 기록된다

## Clarifications

### Session 2 (2026-05-22)

- **#1 본문 저장 입도** → **조(條) 단위로 저장.** 항·호는 본문 텍스트 내 마크업으로 표현. (`OrdinanceSection`이 조 단위, data-model §6 해소) → FR-016 해소
- **#2 출력 형식 범위** → **v1은 DOCX/PDF만 지원, HWP/hwpx는 후순위.** PoC 후 별도 결정. → US9·FR-013 갱신
- **#3 국가법령정보센터 OpenAPI** → **API 키·권한 확보됨/확보 예정.** US7 타 지자체 검색을 v1 범위에 포함. → US7 v1 유지
- **#4 (헌법 P1 강화)** → AI는 입안·정비 기준에 **근거가 없는 내용은 "기준에 없음"으로 명시 표시**해야 한다. 근거를 지어내지 않는다. → FR-005a 추가

## Out of Scope (v1)

- 다수 조례 동시 입안 (한 번에 한 프로젝트)
- 다중 사용자·권한·승인 흐름
- 모바일 입력 (768px 미만 비지원)
- 조례 외 행정규칙·훈령
- 의회 제출 후 심의 트래킹
